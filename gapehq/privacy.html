수집하는 정보

GapeHQ는 사용자가 Google 계정으로 연결한 본인 유튜브 채널의 분석 데이터(조회수, 시청 시간, 구독자 변화)를 YouTube Analytics API의 읽기 전용 권한(yt-analytics.readonly)으로만 가져옵니다.

보관과 이용

가져온 데이터와 인증 토큰은 사용자 본인 컴퓨터에만 저장되며, 채널 성과를 보여 주는 용도로만 씁니다. 어떤 서버로도 전송하지 않고, 제3자와 공유하거나 판매하지 않으며, 광고에 쓰지 않습니다.

삭제

앱 데이터 폴더를 지우거나 Google 계정 권한 페이지에서 GapeHQ 접근을 해제하면 언제든 삭제·중단할 수 있습니다.

English

GapeHQ reads analytics for the user's own YouTube channel through the read-only YouTube Analytics scope. The data and the OAuth token are stored only on the user's computer and used only to display channel performance. Nothing is sent to any server, shared with third parties, sold, or used for advertising. Access can be revoked at any time from the Google Account permissions page.

GapeHQ's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
